# Approximation Algorithms

Cool approximation algorithms, along with their mathematical proofs are added here. 

1. Approximation algorithms for the metric and asymmetric traveling salesperson problem (TSP). The metric TSP admits two classical results, namely, the double tree algorithm and Christofides algorithm. The asymmetric case includes the simple TSP heuristics (such as, cheapest insertion, nearest neighbor and the greedy algortihms) as we know the worst-case guarantees for these algorithms. Frieze et al.[^1] gave the first nontrivial $\log_{2} n$-approximation algorithm in 1982 which was subsequently improved to slightly better factors of $\log_{2} n$. This algorithm is referred to as the *Repeated Assignment Heuristic* or more recently (and commonly) as the *Cycle Cover Algorithm* or *Cycle Shrinking Algorithm*. The major breakthrough in this field was the $O(\log n / \log \log n)$ -approximation algorithm due to Asadpour et al.[^2] (breaking the 30 year barrier of improvements of the $O(\log n)$-approximation). The open problem for a constant factor approximation for the asymmetric case has been solved as of 2022, however they weren't covered in this work.[^3] One can only appreciate the monograph, as it is really well structured (they also cover the important graph theoretic results, sometimes with proofs which makes it easier to follow) and it contains pretty much everything there is to approximation algorithms for TSPs.

This work is a part of the project studies at the Chair of Operations Research, Technical University of Munich. Overall, we cover the works of Frieze et al. and Asadpour et al. in detail. Inspired by the ideas of Christofides and Asadpour et al., we also present a novel heuristic that builds upon the Held-Karp relaxation which finds reasonably good solutions in very little computation time (e.g., less than 10 seconds for a graph with 150-200 nodes). The real world (A)TSP instances were from [Amazon](https://registry.opendata.aws/amazon-last-mile-challenges/) as part of their Last Mile Delivery Routing challenge from 2018.

[^1]: Frieze, A., M., Galbiati, G., Maffioli, F. "On the Worst-Case Performance of Some Algorithms for the Asymmetric Traveling Salesman Problem" (1982)
[^2]: Asadpour, A., Goemans, M. X., Madry, A., Gharan, S., O., Saberia, A. "An O(log n/log log n)-approximation Algorithm for the Asymmetric Traveling Salesman Problem." (2017)
[^3]: Traub, V., Vygen, J. "Approximation Algorithms for the Traveling Salesman Problems" (2024)

2. Scheduling unit-length jobs with arbitrary precedence relations over identical parallel machines. Mathematically, a precedence relationship over jobs is represented by a directed acyclic graph (DAG), $G=(V,A)$ where $A$ represents the set of arcs depicting the precedence relation between two vertex jobs or a partially ordered set (poset), $P=(X,\prec)$ where $X \subseteq V$ are the set of jobs in the poset, ordered by $\prec$. Both of these structures are often used to study scheduling problems with precedence relations. For a variable number of machines, this problem is NP-hard. For constant number of machines, the simplest is the two-machines case for which there is polynomial-time algorithm.[^4] The three-machine case had been an open problem from the days of Garey and Johnson's *Guide to NP-completeness Theory*, until recently proven to be in $P$ by OpenAI (currently unverified, unfortunately I'm no longer working on verifying it, as it is really hard to read and the polynomial time bound itself is pretty demotivating along with the endless recursion which brings out no beautiful theoretical ideas like other precedence constraint scheduling problems). Back to the variable machine case, there have been very fruitful results in recent times such as the quasi-polynomial time approximation scheme (QPTAS) using linear programming hierarchies[^5] as well based on combinatorial guesses.[^6] The problem of finding a PTAS is still open.[^7]

[^4]: Coffman, E., G., Jr., Graham, R., L. "Optimal Scheduling for Two-Processor Systems" (1972)
[^5]: Garg, S. "Quasi-PTAS for Scheduling with Precedence using LP Hierarchies" (2017)
[^6]: Das, S., Wiese, A. "A Simpler QPTAS for Scheduling Jobs with Precedence Constraints" (2025)
[^7]: Li, S. "Towards PTAS for Precedence Constrained Scheduling via Combinatorial Algorithms" (2020)
